Aura

Suomalaisen avoimen datan hakupalvelu — {{ stats.total_datasets }} aineistoa {{ sources|length }} lähteestä, yhdestä paikasta haettuna.

Aura kerää Suomen avoimen datan aineistojen metatiedot samaan hakemistoon: Tilastokeskus, THL, Luke, SYKE, Ilmatieteen laitos, kunnat, eduskunta ja kymmenet muut. Voit selata niitä täällä tai liittää Auran suoraan tekoälyavustajaasi.

Liitä tekoälyavustajaan (MCP)

Aura puhuu Model Context Protocolia. Lisää tämä asiakkaasi asetuksiin, niin avustaja osaa hakea ja lukea aineistoja puolestasi: 

{
  "mcpServers": {
    "aura": { "url": "{{ base_url }}mcp" }
  }
}

Endpoint: {{ base_url }}mcp — ei vaadi tunnuksia. Palvelu on vain luku: hakutyökalut ovat käytössä, kantaa muokkaavat eivät.

Avointa lähdekoodia — aja itse

Aura on MIT-lisensoitu ja koodi on kokonaan julkista. Voit ajaa oman instanssin omalla koneellasi tai palvelimellasi — myös tämä sivu ja MCP-endpoint tulevat samasta repositoriosta. 

git clone https://github.com/trotor/aura
cd aura && python -m venv .venv
source .venv/bin/activate
pip install -e .
aura serve --http

Lähdekoodi ja ohjeet: github.com/trotor/aura. Tietokanta on osa repositoriota, joten aineistot ovat mukana heti kloonauksen jälkeen — harvestointia ei tarvitse ajaa itse.
